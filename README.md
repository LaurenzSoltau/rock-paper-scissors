# Rock Paper Scissors

Rock paper scissors against the computer, written in plain HTML, CSS and JavaScript.

## Features

- Pick a symbol and play a round against a random computer choice
- Both picks and the result of the round are shown each turn
- First to 5 points wins, then the board locks until you hit restart

## Running it

Open `index.html` in a browser.
